Target groups

A group is a saved set of VENs and resources that can be targeted by events, report requests and test runs. Optionally give it an OpenADR groupID: events sent to whole-VEN members then also carry eiTarget/groupID, which VENs configured with that id may honour (OpenADR 2.0b does not require it). Members that are individual resources are addressed by resourceID only, because a groupID applies to everything a VEN controls.
